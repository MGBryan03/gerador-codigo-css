 Desenvolvi uma aplicação web capaz de transformar descrições escritas pelo usuário em código e uma visualização do resultado.

O funcionamento é simples: o usuário descreve o que deseja criar — por exemplo, uma animação ou elemento visual — e a aplicação envia essa solicitação para uma API de Inteligência Artificial. A resposta recebida é processada e exibida na própria interface, mostrando tanto o código gerado quanto o resultado visual em tempo real.

O projeto envolve um fluxo completo de desenvolvimento, desde a interação do usuário até a integração com uma API externa e a renderização dinâmica do resultado.

Tecnologias utilizadas:
HTML para a estrutura da aplicação;
CSS para estilização, layout e interface;
JavaScript para a lógica e interatividade;
Fetch API para comunicação com serviços externos;
Async/Await para requisições assíncronas;
API de Inteligência Artificial para geração dinâmica do código;
Manipulação do DOM para atualizar o código e o preview automaticamente.

O fluxo da aplicação funciona da seguinte forma:

Usuário descreve uma ideia → JavaScript envia a solicitação para a IA → a API processa a solicitação → o código é retornado → a aplicação exibe o código e renderiza o resultado visual.

Esse projeto foi uma oportunidade de aplicar, na prática, conceitos de desenvolvimento Front-End, integração de APIs, requisições HTTP, JavaScript assíncrono e manipulação dinâmica da interface.
